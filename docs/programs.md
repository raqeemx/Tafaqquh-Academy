# صلاحيات البرامج والمحتوى

| المستند                                  | الحقول الأساسية                                                                    | الإذن                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `students/{uid}`                         | uid, email, displayName, status, createdAt, updatedAt, consentVersion, consentedAt | الطالب يقرأ نفسه؛ ينشئ pending؛ يجدد الموافقة فقط                           |
| `programs/{programId}`                   | title (نص معتمد), published (boolean)                                              | الطالب المسجل والمقبول والموثق يقرأ برنامجه المنشور                         |
| `students/{uid}/enrollments/{programId}` | active (boolean), changedBy, updatedAt                                             | الطالب يقرأ تسجيلاته؛ الخادم الإداري يكتب                                   |
| `restrictedContent/{id}`                 | programId, title, body (نص), published (boolean)                                   | البرنامج منشور، والتسجيل نشط، والطالب مقبول وموثق وموافق على النسخة الحالية |
| `studentAdministration/{uid}`            | reason, actorUid, updatedAt                                                        | الإدارة الخلفية فقط                                                         |
| `administrators/{uid}`                   | role=admin, active=true                                                            | هوية IAM الموثوقة فقط تمنح الدور                                            |
| `admissionAudit/{id}`                    | actorUid, actorEmail, studentUid, action, from, to, reason, programId, at          | الإدارة تقرأ عبر API؛ كتابة القرار والسجل في معاملة واحدة                   |

القبول لا يمنح جميع المواد. المادة تتبع برنامجًا واحدًا في هذا النموذج؛ للوصول إليها يلزم التسجيل الصريح فيه. لا توجد wildcard تمنح صلاحيات لكل البرامج. قواعد العميل وخادم API يطبقان الشروط نفسها؛ جميع المسارات الأخرى مغلقة افتراضيًا.

## الانتقال من PR #2

لا تغير حالات الطلبات القديمة تلقائيًا. الطلاب دون إصدار الموافقة الحالي يجددون الموافقة من `/student`. المحتوى القديم دون `programId` لن يكون متاحًا حتى ينسبه مشغّل موثوق إلى برنامج معتمد وينشئ التسجيلات المطلوبة. لا تنشئ تسجيلات عامة لكل المقبولين آليًا. اختبر بعينة وهمية في Staging قبل أي ترحيل حقيقي، وراجع أثر القواعد قبل نشرها.

أنشئ البرامج والمواد المعتمدة فقط عبر مسار إدارة موثوق (Console/IAM في المرحلة الحالية). لا تستخدم أسماء كتب أو مواد أو تسجيلات غير مصرح بها. استخدم معرفات أحرف وأرقام وشرطة/شرطة سفلية، بحد أقصى 128 حرفًا. طبّق الفهارس المرفقة وانتظر اكتمالها قبل تجربة البحث. Storage مغلق؛ يلزم تصميم مستقل لروابط وسائط قصيرة العمر ومقيدة بالبرنامج قبل إضافة التسجيلات.
