# الاحتفاظ وحدود التشغيل

السياسة البرمجية المقترحة للمراجعة قبل الاستخدام الحقيقي:

| السجل | الصلاحية | الحذف الفعلي |
| --- | --- | --- |
| driveScans ومعاينة candidates | ٧ أيام ثابتة من الإنشاء، حتى للمعاينات القديمة | زر «تنظيف السجلات المنتهية» من إدارة المكتبة |
| mediaSessions | ٥ دقائق؛ الطلب المفقود أو المنتهي مرفوض فورًا | الزر نفسه يحذف الأذونات المنتهية |
| playbackUsage | حصة ثابتة لكل طالب/ساعة UTC | يصبح قابلًا للحذف بعد ٢٤ ساعة من انتهاء نافذة الساعة |

انتهاء الصلاحية تلقائي عند التحقق على الخادم، أما الحذف المادي فهو صيانة يدوية يومية على دفعات حتى اكتمالها. لا توجد خدمة Cron/TTL مدفوعة أو مهمة سحابية منشأة. زر التنظيف لا يحتاج Terminal، ويتحقق من دخول المسؤول الحديث ودوره الحي داخل المعاملة، ويسجل أعداد المحذوفات في Audit Log دون بيانات مصدر. لا يحذف الدروس أو الفهرس المعتمد أو سجل التدقيق أو ملفات Drive.

كل ضغطة تحذف حتى ١٠٠ إذن تشغيل و١٠٠ سجل استهلاك و٢٠٠ عنصر من معاينة واحدة منتهية. لا يُحذف مستند المعاينة قبل استنزاف عناصره الفرعية، لأن Firestore لا يحذفها تلقائيًا مع الأب. يعالج التنظيف المعاينات القديمة باستخدام createdAt، ولا يمدد انتهاءها. المستندات القديمة المشوهة التي تفتقد createdAt لا تُقرأ وتحتاج معالجة مشغّل موثوق؛ لم تُجرَ معالجة أو كتابة على قاعدة البيانات الحقيقية.

## حدود التشغيل

- النطاق الواحد لا يتجاوز 8 MiB مهما كان حجم الملف. تُرفض النطاقات المتعددة والمعيبة والأعداد غير الآمنة بـ416.
- الحد الافتراضي لحجم ملف قابل للتشغيل 10 GiB عبر `DRIVE_MAX_FILE_BYTES`، قابل للخفض أو الرفع حتى 100 GiB. الملف الأكبر يُرفض بـ413 دون تنزيله.
- لكل طالب في الساعة UTC: 600 طلب إصدار إذن/تشغيل و2 GiB نطاقات محجوزة. تضبطها `PLAYBACK_HOURLY_REQUESTS` و`PLAYBACK_HOURLY_BYTES` ضمن حدود معلنة في الكود. الحجز ذري في Firestore لمنع تجاوز الحد بطلبات متزامنة، ولا يُسترد إذا فشل المصدر أو ألغى العميل الطلب، تجنبًا لإساءة إعادة المحاولة. التجاوز يعيد 429؛ واجهة التسجيلات تعيد Retry-After.
- مهلة المصدر 25 ثانية للبيانات الوصفية و90 ثانية لنطاق التسجيل، مع إلغاء النقل إذا أغلق العميل الطلب. لا إعادة محاولات تلقائية غير محدودة. لا قراءة ملف كامل في الذاكرة؛ يتأكد الخادم من 206 وContent-Range والحجم الفعلي ويرفض الاستجابة الكاملة أو المبتورة أو الزائدة.
- تستخدم الملفات الصوتية audio والمرئية video، دون تحميل مسبق قبل ضغط التشغيل. لا تحويل ترميز. أنواع المتصفحات وصيغ التسجيلات الفعلية تحتاج اختبارًا محدودًا بعد إذن المالك.

هذه حدود لكل طالب وليست سقف فاتورة عالميًا أو حماية كاملة من إساءة الاستخدام الموزعة؛ يلزم تقييم الحمل والمراقبة قبل الاستخدام الحقيقي. لا تزيل الحدود تكلفة Firestore أو نقل البيانات إذا فُعّلت خدمة فعلية لاحقًا. فحص الصلاحية يتكرر عند كل نطاق؛ لا يمكن استرجاع أجزاء سبق تسليمها لمستخدم كان مصرحًا.
