# فهرسة Google Drive — قراءة فقط

المسار `/admin/library` يختار مجلدًا رئيسيًا مسموحًا أو مجلدًا فرعيًا داخله، ويقرأ صفحات Drive والمجلدات المتداخلة. يعرض المسار والتصنيف المقترح من المجلد واسم الملف ومعرّفه ورابط المصدر ورقم الدرس إن كان واضحًا. لا يستنتج تاريخًا أو اسم كتاب أو نسبة علمية من عنده. الأرقام العربية والفارسية واللاتينية مدعومة؛ السنوات لا تعامل تلقائيًا كأرقام دروس.

أنشئ البرامج والمواد والكتب والسلاسل أولًا من إدارة المحتوى، ثم اربط كل تصنيف مجلد بالسلسلة المناسبة في المعاينة. عدّل العناوين والأرقام، وحدد التسجيلات التي راجعتها، ثم اعتمدها. يمكن إيقاف قراءة المجلدات واستئنافها بمعرّف المعاينة. المعاينة خاصة بالمسؤول الذي أنشأها. تعرض 10 ملفات في الصفحة، والاعتماد المحدد متسلسل بحيث يمكن إعادة المحاولة بعد انقطاع الشبكة.

يحفظ `driveScans` المعاينة، و`driveAssets` بيانات المصدر الخاصة، و`catalog` درسًا مسودة بمعرف حتمي مشتق من معرف ملف Drive. إعادة المزامنة لا تضاعف الدرس ولا تستبدل العنوان أو التصنيف أو الترتيب أو حالة النشر التي عدلتها يدويًا. الملف نفسه يُفهرس كدرس واحد، حتى عند إعادة اختيار جذر آخر. عدّل الدرس من إدارة المحتوى بعد الاستيراد. لا توجد كتابة إلى Google Drive، ولا حذف أو نقل أو تعديل مشاركة؛ الاختصارات والملفات غير الصوتية/المرئية متجاهلة. حذف المصدر أو نقله خارج النطاق لا يحذف الفهرس تلقائيًا؛ يفشل فتح التسجيل بأمان.

حدود المعاينة الواحدة: 250 مجلدًا، 10000 تسجيل، مسار بطول 1000 حرف. إن تجاوزت الحدود اختر مجلدًا فرعيًا أصغر. يعيد Drive الصفحات تدريجيًا؛ البحث غير المكتمل لا يُعتمد. راجع احتفاظ وحذف معاينات `driveScans` إداريًا قبل الاستخدام الفعلي؛ لا ينشئ هذا التغيير وظيفة حذف تلقائية أو TTL سحابية.

## الربط الحقيقي بعد الإذن فقط

التكامل معطل افتراضيًا. لا تضع credentials أو tokens في NEXT_PUBLIC أو المستودع. استخدم هوية ADC موجودة ومصرحًا لها مسبقًا بقراءة المجلد، أو تفويض OAuth لحساب مالك/قارئ لديه الوصول أصلًا. لا تغير مشاركة الملفات لأجل هذا الربط. OAuth يستخدم client معتمدًا وإذن `drive.metadata.readonly` للفهرسة، و`drive.readonly` للتشغيل عند تفعيله. بعض النطاقات تحتاج مراجعة تطبيق OAuth حسب طريقة استخدامه؛ لا ننفذ تفويضًا أو طلب وصول حقيقي هنا.

بعد موافقة المالك على الربط، يتحقق المشغّل من تفعيل Drive API في المشروع الحالي، ويجهز الاعتماد خارج المستودع، ويضع DRIVE_ALLOWED_ROOTS لمعرفات المجلدات المسموحة فقط (حتى 20 جذرًا)، ثم DRIVE_ENABLED=true وDRIVE_PROVIDER=google. DRIVE_MEDIA_ENABLED يبقى false حتى الموافقة على قراءة التسجيلات. لا API keys للقراءة الخاصة ولا روابط عامة بديلة. لا حسابات أو مشاريع أو بيئات جديدة مطلوبة من هذا الكود؛ لا تنفّذ أي خطوة سحابية تلقائيًا.

## المحاكاة

`DRIVE_PROVIDER=mock` يعمل فقط مع APP_ENV=local ومشروع demo-tafaqquh ومحاكيات Firebase، ولا يعمل في production. البيانات الاصطناعية تختبر صفحات متعددة، مجلدات متداخلة، ملفًا غير تسجيل واختصارًا، رقم درس عربي، اعتمادًا كمسودة، ثم إعادة المزامنة مع بقاء التعديل اليدوي. لا تُقرأ تسجيلات الشيخ أو حساب Google الحقيقي في الاختبارات.
