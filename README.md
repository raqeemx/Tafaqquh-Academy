# أكاديمية تفقّه

منصة عربية RTL على Next.js 16.4.3 وTypeScript وTailwind CSS وFirebase. بُني هذا التحديث على `main` بعد دمج PR #2 (`d6f389c`)، مع الحفاظ على الهوية والصفحات والمصادقة الموجودة.

## التشغيل

Node.js 24.12+، ثم `npm ci` و`npm run dev`. انسخ `.env.example` إلى `.env.local` واملأ إعدادات تطبيق الويب الخاص بالبيئة المطلوبة. لا تضع مفاتيح خدمة في المستودع. تعمل الصفحات العامة دون إعداد Firebase؛ التسجيل يتوقف بأمان حتى تفعيل المصادقة واعتماد سياسة الخصوصية وملء بيانات مسؤول معالجة البيانات والتواصل والاحتفاظ.

| المسار                | الوظيفة                                                                    |
| --------------------- | -------------------------------------------------------------------------- |
| `/` و`/new-student`   | التعريف ودليل البداية وزر إنشاء الحساب                                     |
| `/register` و`/login` | التسجيل بموافقة صريحة، الدخول واستعادة كلمة المرور                         |
| `/student`            | تأكيد البريد وحالة الطلب وتجديد الموافقة والبرامج المصرح بها               |
| `/admin`              | إدارة الطلبات والبحث والقبول والرفض والتعليق وصلاحيات البرامج وسجل التدقيق |
| `/privacy`            | سياسة قابلة للمراجعة؛ تبقى مسودة حتى اعتمادها                              |

## الإعداد والأمان

- [دليل Firebase](docs/firebase.md): المتغيرات وConsole والمحاكيات.
- [دليل الإدارة](docs/admin.md): تعيين أول مسؤول وتشغيل اللوحة دون Terminal للاستخدام اليومي.
- [صلاحيات البرامج](docs/programs.md): نموذج البيانات وترحيل المحتوى القديم.

تتطلب المادة المقيدة بريدًا موثقًا، وقبولًا حاليًا، وموافقة خصوصية حالية، وتسجيلًا نشطًا في البرنامج المنشور. تتحقق الواجهات الخلفية من الهوية والصلاحيات عند كل طلب؛ إخفاء الأزرار ليس وسيلة الحماية. لا يتضمن المشروع مواد منسوبة للشيخ أو بيانات طلبة حقيقية.

## البنية

`src/app` للمسارات وواجهات الخادم، `src/components` للمكونات المشتركة، `src/features/auth` و`src/features/admin` لتجربتي الطالب والمسؤول، `src/lib/firebase` و`src/lib/server` للبنية الموثوقة، `tests/security` للقواعد ودورة العمل الكاملة.

## التحقق

```sh
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm test
npm run test:rules
```

تحتاج اختبارات القواعد إلى Java 21. تستخدم Auth وFirestore Emulator فقط في مشروع `demo-tafaqquh` الوهمي، وتشغّل متصفحًا لدورة التسجيل والتأكيد والقبول ومنح البرنامج وسحبه والتعليق ومنع الوصول غير المصرح. اختبارات `npm test` تفترض بناءً مع `NEXT_PUBLIC_FIREBASE_AUTH_ENABLED=false`. لا تعِد استخدام خادم dev قديم عند فحص بناء الإنتاج.

## حدود التسليم

لا نشر أو دمج تلقائي ولا إنشاء موارد مدفوعة. لا تكفي اختبارات المحاكيات لاعتماد الإنتاج؛ يلزم اختبار Staging منفصل، وفحص IAM والبريد والفهارس وApp Hosting. أبقينا Next.js 16.4.3؛ الإصدارات الأحدث من جدول Firebase النشط تُعامل كمعاينة، ويلزم اختبار محوّل App Hosting فعليًا بعد الموافقة على النشر. إدارة إنشاء البرامج والمواد ليست ضمن هذه اللوحة؛ تعرض فقط البرامج المنشورة التي أدخلتها إدارة موثوقة. راجع AGENTS.md قبل التعديل.
