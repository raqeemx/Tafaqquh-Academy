# أكاديمية تفقّه

منصة عربية RTL مبنية بـNext.js 16.4.3 وTypeScript وTailwind CSS، مع Firebase Authentication وCloud Firestore لمشروع **tafaqquh-academy** الموجود.

## التشغيل

استخدم Node.js 22، ثم:

```sh
npm ci
npm run dev
```

افتح http://localhost:3000. تعمل الصفحات العامة دون إعداد Firebase؛ التسجيل يبقى معطّلًا بأمان حتى اكتمال إعداد الخدمة.

- `/`: الرئيسية ومنهج التعلم.
- `/new-student`: دليل البداية.
- `/register`: إنشاء حساب وإرسال طلب قبول.
- `/login`: دخول واستعادة كلمة المرور.
- `/student`: تأكيد البريد، حالة الطلب، واستعادة الطلب غير المكتمل.
- `/api/student/content`: بيانات مقيدة، تتحقق من الهوية والقبول في كل طلب.

راجع **[دليل Firebase والإعدادات الناقصة](docs/firebase.md)** قبل تفعيل التسجيل. توجد قيم تطبيق الويب المحلية في `.env.local` المستثنى من Git؛ لا يحتوي المستودع مفاتيح خدمة. ملف `.env.example` يوضح جميع المتغيرات.

## البنية

```text
src/app/              الصفحات وواجهات الخادم
src/components/       المكونات المشتركة
src/features/auth/    نماذج الدخول وحالة الطالب
src/lib/firebase/     Client وAdmin منفصلان
scripts/              أدوات المشغّل الموثوق
 tests/               اختبارات المتصفح والأمان
```

القبول يتطلب بريدًا موثّقًا وحالة `approved`. لا يستطيع الطالب تغيير القرار أو قراءة طلبات الآخرين. Admin يستخدم ADC ويظل على الخادم؛ قواعد Firestore تمنع الوصول المباشر غير المصرح به. الصفحات لا تتضمن مواد الشيخ أو بيانات طلبة حقيقية.

## الجودة

```sh
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm test
npm run test:rules
```

اختبارات الأمان تحتاج Java 21 ومحاكيات Firebase. بياناتها اصطناعية ومحلية فقط، ولا تتصل بالمشروع الحي. التفاصيل في دليل Firebase. GitHub Actions يفحص الأنواع والبناء والمتصفح والقواعد، ولا ينشر التطبيق.

## الاستضافة وحدود المرحلة

البنية مهيأة لأوامر Next.js build/start وNode.js 22 وملف القفل. [توثيق Firebase](https://firebase.google.com/docs/app-hosting/frameworks-tooling) يصنّف إصدارات Next.js الأحدث من جدول active كمعاينة؛ لم يُختبر نشر فعلي على App Hosting. لم تُفعّل خدمات مدفوعة أو تُنشأ موارد سحابية أو يُنشر التطبيق أو القواعد.

الهوية والمحتوى وسياسة الخصوصية ولوحة الإدارة تحتاج اعتمادًا وتطويرًا لاحقًا. أداة القبول الحالية للمشغّل الموثوق فقط. راجع AGENTS.md قبل التعديل.
