# أكاديمية تفقّه

المرحلة التأسيسية لمنصة تعليمية شرعية عربية بالكامل، باستخدام Next.js App Router وTypeScript وTailwind CSS وFirebase Web SDK.

## التشغيل والمراجعة محليًا

المتطلب: Node.js 22 وnpm. لا تحتاج إلى حساب Firebase لتشغيل هذه المرحلة.

```sh
npm ci
npm run dev
```

افتح http://localhost:3000، ثم راجع:

- `/`: الرئيسية ومنهج التعلّم وروابط البداية.
- `/new-student`: دليل الطالب الجديد وأسئلة تفاعلية.
- `/login`: تصميم أولي مع التحقق من الحقول وإظهار/إخفاء كلمة المرور. لا ينفّذ مصادقة ولا يرسل أو يخزّن بيانات.
- أي مسار غير موجود: صفحة 404 عربية.

لا تدخل بيانات حقيقية في نموذج المعاينة. لا توجد دروس أو تسجيلات أو بيانات طلاب أو شهادات مختلقة في المشروع.

## الفحوص

```sh
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm test
npm audit
```

لاختبار نسخة الإنتاج يدويًا بعد البناء: `npm start`.
يمكن استخدام Chrome المثبّت بدل تنزيل Chromium على PowerShell:

```powershell
$env:PLAYWRIGHT_CHANNEL='chrome'
npm test
```

تشمل اختبارات Playwright: اللغة واتجاه RTL، التنقل، الأسئلة القابلة للفتح، التحقق من النموذج، إظهار وإخفاء كلمة المرور، عدم إرسال طلبات بيانات، استجابة الصفحات وعدم تجاوز العرض على الهاتف والحاسوب، وصفحة 404. يشغّل GitHub Actions الفحوص والبناء والاختبارات على Node.js 22، دون نشر.

## الهيكل

```text
src/
  app/                  # الصفحات والتخطيط وبيانات SEO والتنسيق
  components/           # رأس الصفحة وتذييلها والمكونات المشتركة
  features/auth/        # واجهة معاينة الدخول
  lib/firebase/         # تهيئة Firebase الكسولة
 tests/                 # اختبارات المتصفح
```

المكونات خادمية افتراضيًا؛ نموذج الدخول فقط مكوّن عميل. التصميم متجاوب ويدعم لوحة المفاتيح وحالات التركيز وتقليل الحركة. لا يعتمد البناء على تنزيل خطوط أو صور من خدمات خارجية.

## Firebase

انسخ `.env.example` إلى `.env.local` فقط عند وجود مشروع Firebase معتمد، ثم انسخ القيم الفعلية من إعدادات تطبيق الويب في Firebase Console. تُترك جميع القيم فارغة في المثال عمدًا.

`src/lib/firebase/client.ts` يوفّر `getFirebaseClient()`؛ يُرجع `null` على الخادم أو عند نقص أي قيمة، ويعيد استخدام التطبيق الافتراضي عند اكتمال الإعداد في المتصفح. لا يستدعيه نموذج المعاينة ولا تبدأ أي خدمة أو اتصالات عند استيراده. لا يوجد Admin SDK ولا مفاتيح خدمة ولا Analytics في هذه المرحلة.

قيم `NEXT_PUBLIC_*` عامة وتُضمَّن وقت البناء؛ ليست مكانًا للأسرار. قبل تفعيل الحسابات لاحقًا يلزم إعداد موفّري المصادقة، التحقق الخادمي من الجلسات والصلاحيات، قواعد Firestore/Storage واختبارها بالمحاكيات، وسياسة خصوصية معتمدة. لا توجد قاعدة بيانات متصلة الآن، ولا يصح اعتبار تهيئة SDK وحدها حمايةً للبيانات.

## Next.js وFirebase App Hosting

- ثُبّت Next.js **16.4.3**، الإصدار المستقر الأحدث في npm عند الإعداد بتاريخ 26 أكتوبر 2026، مع إصدارات محددة وملف `package-lock.json`.
- إعداد Node.js في `engines` هو **22.x**. أوامر `build` و`start` وملف القفل مهيأة لنموذج بناء App Hosting المعتاد، دون تصدير static-only.
- [توثيق Firebase الرسمي](https://firebase.google.com/docs/app-hosting/frameworks-tooling) يوضح أن إصدارات الأطر الأحدث من النسخة المصنفة active تكون **preview**. الجدول المنشور وقت المراجعة لا يدرج Next.js 16 ضمن الدعم النشط؛ لذا لا ندّعي تحقق النشر أو ضمان الدعم النشط لهذا الإصدار.
- [إصدارات Next.js الرسمية](https://github.com/vercel/next.js/releases) و[سياسة الدعم](https://nextjs.org/support-policy).
- لم يُنشأ backend أو مشروع Firebase، ولم يُربط فرع بالنشر التلقائي، ولم تُفعّل فوترة أو خدمات مدفوعة. التحقق الفعلي من محوّل App Hosting يتطلب مرحلة مستقلة مصرحًا بها قبل أي إطلاق. لا حاجة إلى `apphosting.yaml` ما دامت الإعدادات الافتراضية كافية؛ تُضاف إعدادات البيئة الفعلية عند اعتماد تلك المرحلة.

## اعتماديات الأمان

يوجد override لـ `@grpc/grpc-js` إلى `1.14.6` لمعالجة التنبيهات التي تصل عبر اعتماد Firestore الفرعي في Firebase. لا يُستخدم Firestore في هذه المرحلة. راجع الحاجة إلى override عند ترقية Firebase؛ ولا تستخدم `npm audit fix --force` الذي يقترح الرجوع إلى Firebase قديم. نتيجة التدقيق عند الإعداد: صفر ثغرات معلنة.

هذه أساس واجهة وبنية مشروع قابلة للتوسعة، وليست نظام إدارة تعلم مكتملًا. الحسابات والدروس ولوحة الطالب والإدارة والدفع والمراسلات غير مفعلة. يجب اعتماد المحتوى والهوية الرسمية واسم الشيخ قبل إضافتها. راجع `AGENTS.md` لتعليمات المساهمين.
